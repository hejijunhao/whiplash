# v0.9 hardware session: the ontology on a Digitakt II

One ordered session for Phil on the Air, with Hermes and a Digitakt II on USB MIDI. It covers **everything the ontology added, v0.9.0 to v0.9.5** (O1a, O1b, O2, O3, O4, O5 and the post-O5 audit). It merges the per-phase checks:
- [hardware-checklist.md](hardware-checklist.md) Part O, checks O1-O21,
- spec §8 HW O-1 to O-8,
- the O2 plan's HW O-9 to O-12,
- reference §15.3 Q32-Q53.

It replaces running Part O there: the checks are the same, reordered so that each genre is set up once and the kit changes as little as possible, plus the checks for what the audit changed (V10, V27 to V29).

**Nothing in this file is verified yet.** The test suite runs on fake and virtual ports only. Every value below is a proposed default from [the spec](../executing/ontology-v1-spec.md). Tick Pass or Fail as you go and jot a note. Afterwards, record each result in [reference.md](../digitakt-ii/reference.md) §15.3 with who tested it, the date and the OS version (CLAUDE.md rule), as [Recording the results](#recording-the-results) says.

**Time:** about 90 minutes for everything. If time is short, run **S** (smoke, 15 min) and the starred checks (★, about 40 min): they cover the demo sentence and the defaults a weak model leans on.

**Order and why:**
- **0** sets up the gateway, the unit and the listening extras once.
- **S** is the smoke test: the demo path, unchanged since v0.8, and the bit-for-bit promise.
- **G, H, D, T, K** go genre by genre: deep-house grooves; Chicago house; deep-house harmony; tech house; techno.
- **N** is the four O3 genres.
- **M** is the arrangement moves and forms.
- **L** is the taste review with a listen, plus the thresholds by ear. It runs last because it needs the most bars of untouched playing.

Type the prompts as written; *italic* text is a placeholder. If Hermes picks a different tool or argument from the one shown, note it: that's useful too. The prompts assume Phil's project 6 as of Nov 11 (tracks 7-8 tuned cymbals, slot 9 a "dirty bass", slot 11 a synth). For the harmony checks, **relabel 7 and 8 as chord tracks** in D0, because Whiplash never puts chords on a cymbal.

## 0. Before you start (10 min)

### 0.1 Update and restart the gateway
```bash
git -C ~/whiplash pull          # symlinked checkout; or: hermes plugins update whiplash
hermes gateway restart          # required: the gateway keeps old plugin code until it restarts
hermes plugins list             # whiplash -> enabled (v0.9.5, 26 tools)
```
- A new chat is **not** enough after an update. Only a gateway restart loads the new code.
- Delete any skill Hermes auto-created for Whiplash under `~/.hermes/skills/`.
- Start a **new chat**.
- [ ] `hermes plugins list` shows v0.9.5 and 26 tools.

### 0.2 Clock timing (2 min, no unit needed)
```bash
uv run python scripts/clock_jitter.py --runs 2
```
- [ ] Write down `late_p50`, `late_p99`, `sleep_p50`. V1's microtiming is 5-15 ms, so **if `late_p99` is above 5 ms**, note it: V1 may be inside the jitter ([clock-jitter.md](clock-jitter.md)).

### 0.3 On the unit
As [hardware-checklist.md](hardware-checklist.md) §0.3:
- INPUT FROM USB, RECEIVE NOTES and CC on, CLOCK and TRANSPORT RECEIVE on.
- Tracks 1-8 on channels 1-8, with AUTO CHANNEL and FX CONTROL off channels 1-12.
- **USB CONFIG = USB AUDIO/MIDI** (L1 needs audio). **Select an empty pattern**, and **reload it** with [FUNC] + [NO], so TUNE is 64 and the filters are at the preset values.
- **Don't touch project slots 1-3, and don't save.** Whiplash never saves anything and never sends SysEx or program change.

**Note the filter.** The v0.9 checks send `filter_freq` (CC 74) in a few places: the timbral steps (D6), the tech house breakdown (T4), and the energy filter in progressive and melodic techno builds (N2, M4). The cutoff stays where a ramp leaves it until you reload the pattern. **Reload ([FUNC] + [NO]) between blocks** when a check says so.

### 0.4 Listening extras (for L1)
- `whiplash[listen]` installed on the Air (numpy, sounddevice), as Part V of the main checklist. Microphone permission granted.
- [ ] `whiplash_listen` works once: *"Listen for 1 bar."* with anything playing.
